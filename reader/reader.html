How it works: every request is a JSON-RPC call (eth_chainId, arkiv_query) sent from this page to the endpoint above. Muniment's data contract is documented at github.com/TheWeirdDee/muniment/blob/main/arkiv/schema.md. Trust comes from the on-chain creator wallet, not from the namespace, which anyone can copy.

  
If your browser blocks requests from a file opened from disk, serve this folder with any static server, for example python -m http.server, and open http://localhost:8000/reader.html.
